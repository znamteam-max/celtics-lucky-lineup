# Celtics Lucky Lineup

Кнопка с Лепреконом собирает случайную стартовую пятёрку «Бостон Селтикс». Тэйтум всегда на SF, остальные крутятся как в казино. Под составом показывается цитата ведущего «Взял мяч».

Одна страница, без сборки: `index.html` + папки `photos/` и `logos/`.

- Состав и позиции: блок `ROSTER` в начале скрипта в `index.html`.
- Цитаты: блок `HOST_CAPTIONS` там же, формат `q("цитата","Имя Фамилия")`.
